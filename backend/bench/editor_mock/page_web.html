Profile Card

Build a profile card using HTML and CSS.

Scroll down for the requirements and the styles.

Requirements

Use a div element with the class name card. Inside it, add an h1 element with the text Asha Rao, a p element with the class name role and the text Frontend Developer, and a button element with the text Follow.

Styles

The card should have the background color #e8f0fe. The role should have the color #6b7280.

Test Cases

The page should have a div with the class card. The h1 should have the text Asha Rao. The card background and the role color should match the given values.
