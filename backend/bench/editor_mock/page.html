Grade Report

Write a program that reads N, followed by N lines each containing a student name and a mark separated by a space. For each student print the name followed by a colon and the grade: A if mark >= 90, B if mark >= 75, C if mark >= 50, otherwise F. Finally print Top: followed by the name of the student with the highest mark (the first one if tied).

Input

The first line of input is an integer N. The next N lines contain a name and a mark.

Output

N lines of the form name: grade, then the Top line.

Sample Input 1

3
Ravi 92
Asha 67
John 40

Sample Output 1

Ravi: A
Asha: C
John: F
Top: Ravi

Constraints

1 <= N <= 100
