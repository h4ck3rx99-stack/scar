Grade Report

A teacher wants a quick grade report for a class. Write a program that reads the marks of the students and prints each student's grade, followed by the top student.

Read the whole problem carefully. The grading rules and the tie rule are described further below.

Input

The first line of input is an integer N. The next N lines each contain a student name and a mark, separated by a space.

(scroll down for the output rules)

Output

For each student, in input order, print the name, a colon, a space and the grade.

Grades: A if the mark is at least 90, B if at least 75, C if at least 50, otherwise F.

After that print Top: followed by the name of the student with the highest mark. If several students share the highest mark, print the one who appears first in the input.

Sample Input 1

3
Ravi 92
Asha 67
John 40

Sample Output 1

Ravi: A
Asha: C
John: F
Top: Ravi

Constraints

1 <= N <= 100. Marks are integers from 0 to 100.
