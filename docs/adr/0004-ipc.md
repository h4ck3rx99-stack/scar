# ADR 0004: Local IPC: authenticated JSON lines over 127.0.0.1 TCP

Status: accepted (2026-09-26)

## Decision

The daemon listens on 127.0.0.1 with a random port, rejects non-loopback peers, and requires a 256-bit token stored in `<data>/ipc.json` whose DACL grants only the current user. A lock file (msvcrt.locking) enforces one runtime per data folder.

## Alternatives and rationale

A named pipe would avoid the port but complicates asyncio on Windows (proactor pipe servers) for no security gain given the loopback + token + ACL checks.
