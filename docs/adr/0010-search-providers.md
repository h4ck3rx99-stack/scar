# ADR 0010: Search chain: Brave → Tavily → SearXNG → ddgs (unofficial) → cache

Status: accepted (2026-09-26)

## Decision

Brave and Tavily have usable free allowances (checked 2026-09-26; Brave requires a card for identity). SearXNG is self-hosted and free. ddgs is an unofficial scraper used as a keyless fallback; it is documented as unofficial and may rate-limit.
